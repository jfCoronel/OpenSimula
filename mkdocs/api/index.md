# API reference

Reference of the Python classes used to build, run and analyse simulations, generated
from the docstrings of the source code. The parameters and variables of each component
type are described in the [Component list](../component_list.md).

- [Simulation](simulation.md): the simulation environment, entry point of every program.
- [Project](project.md): components, simulation parameters, reading/writing and running.
- [Component](component.md): base class of all the components and their simulation
  methods.
- [Parameters](parameters.md): the parameter containers and the parameter types.
- [Variable and Message](variable.md): simulation results and messages.
- [Iterative_process](iterative_process.md): fixed-point iteration used by the components.
